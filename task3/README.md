**ПРИЗРАК И СКЕЛЕТИК**

Небольшой хэллоуинский платформер (тема вроде как свободная, так что почему нет ('O'))

Собери 3 части скелетика и доставь их в пещеру. Осторожно: шипы, летучие мыши и пропасти!

**УПРАВЛЕНИЕ**

Клавиатура:
- ← → или A D — движение
- Space / W / ↑ — прыжок
- ESC / P — пауза
только англ раскладка
Телефон:
- Экранные кнопки «ЛЕВО», «ПРЫЖОК», «ПРАВО»

**КАК ЗАПУСТИТЬ**

Либо через Github Pages либо через Live Server в VC code


**ЧТО ЗА НЕЙРОСЕТЬ?**

Игра создана с помощью Grok, но по большей части DeepSeek

**ПРОМТИКИ:** 

1. Минимальные требования к результату: есть вот такие правила: Минимальный результат — Один проходимый уровень: персонаж, пять платформ, три предмета, опасная зона и финиш. Управление стрелками/A–D и прыжок Space/W. Повторный прыжок в воздухе запрещён. Гравитация и столкновения: герой стоит на платформе и не проходит через неё. Счёт, победа после сбора предметов и финиша, поражение при падении/опасности. Кнопки старт, пауза, заново; понятная подсказка управления. Пауза при уходе со вкладки, корректный рестарт; рекорд сохраняется. Для телефона — экранные кнопки движения и прыжка.

2. Общее задание и структура проекта: правила остаются , но сделай уровень сложнее, и отрисовку давай сделаем в пиксельном стиле как у динозавра который прыгает если нет интернет соединения, все остальное по правилам сохраняем. сам дизайн страницы тоже сделай более пиксельным. создай по тем же правилам игру, только про призрака который собирает части своей подруги скелетика. нужны index.html, style.css, ES-модули main.js, Game.js, Player.js, input.js и collision.js.

3. дополнение к Player: движение стрелками или A/D, прыжок Space/W, гравитацию. Скорость измеряй в пикселях в секунду, обновление принимает dt. Прыжок доступен только с опоры. При удержании клавиш движение плавное; управление игрой не прокручивает страницу, когда игра активна.

4. игровой цикл дополнение: через requestAnimationFrame: update(dt), затем render(). Вычисляй dt по времени кадра и ограничивай слишком большой шаг после задержки. При старте/продолжении не создавай второй цикл. При скрытии вкладки ставь игру на паузу и очищай нажатые клавиши. На продолжении сбрось время предыдущего кадра.

5. Рестарт полностью сбрасывает героя, предметы и счёт, но не дублирует обработчики и цикл. Лучший счёт сохраняй в localStorage с обработкой ошибок хранения. После победы/поражения игра не обновляется до нового старта.
